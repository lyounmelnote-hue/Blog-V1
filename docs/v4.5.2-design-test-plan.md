# Blog-V1 v4.5.2 — blog-fit + search-intent ranking (design / test-first)

Status: DESIGN ONLY. No production workflow, schedule, approval, or Notion schema modifications in this branch.

## Invariants
- Daily maximum 10; no forced filler; preserve existing cross-category flexible allocation and same-day URL/title dedupe.
- Keep scheduled 10:07/11:07 KST and 60-minute approval watcher unchanged.
- Preserve blocked-content screening, fail-closed evidence checks, human approval, and no auto-publishing.
- Never label Naver blog search result total as actual monthly search volume; report proxy and missing data explicitly.
- Unverified search results are leads, never verified citations.

## Pipeline
1. Collect existing news + blog intent seeds.
2. Apply existing hard safety and URL gates.
3. Calculate blog-fit score (0–100) using explicit, auditable indicators; do not infer a reader's personal attributes.
4. Compute 100-point editorial score: search potential 50 (intent clarity 20, demand proxy 10, SEO 10, evergreen 10); freshness 20 (publication 10, seasonal relevance 10); citation/save value 30 (reusable table/checklist 10, verifiable source potential 10, revisit value 10).
5. Blog-fit >=70: preferred; 50–69: reserve; <50: deprioritized but retain diagnostics. Safety gates never overridden by rank.
6. Select up to 10 flexibly, preserve max 4 per category; never pad with unsafe or empty candidates.
7. Attach explanations: blog_fit_score, intent, content_format, score_parts, evidence_status, scoring_version. Store in existing 검증 메모 initially to avoid schema migrations; introduce new Notion fields only after separate schema review.

## Blog-fit dimensions
- Topic continuity (30): daily-life guidance, culture/books, practical tools, learning, digital how-tos.
- Reader usefulness (30): actionable steps, eligibility, decision support, comparison.
- Search-article transformability (20): explicit question/how-to/checklist structure.
- Internal-link potential (20): coherent clusters of related guide topics. Do not claim actual internal links unless indexed.

## Test-first acceptance criteria

- [ ] A practical free-font installation guide outranks an unrelated corporate announcement when safety/evidence are equal.
- [ ] Search result counts are marked proxy; unavailable count is neutral and logged.
- [ ] A prohibited topic with 100/100 is still rejected.
- [ ] Unverified articles remain 보류 and are never promoted to 안전 by scoring.
- [ ] 10 valid candidates => 10 selected; 6 valid => 6, not fabricated 10.
- [ ] Duplicate normalized URLs, duplicate titles, and same-day already-present entries excluded.
- [ ] A category may backfill up to 4, and existing records count toward 10.
- [ ] DRY_RUN=true performs no Notion writes.
- [ ] Existing workflows and schedule files unchanged; approval polling untouched.
- [ ] Golden set >=30 diverse examples; compare v4.5.1 vs v4.5.2 top-10 precision by manual editorial judgment.
- [ ] Explicitly separate proxy ranking improvements from actual traffic/quotation outcomes, which require post-publication analytics.
